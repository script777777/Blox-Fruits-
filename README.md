# Void Syndicate

Free link bypasser for Linkvertise, Work.ink, Lootlabs, Admaven and more.

## Lokal

```bash
npm install
npm run dev
```

1. Im UI **Add API key** → Key speichern, **oder**
2. `.env` mit `BYPASS_API_KEY=...`

Ohne Key: Demo-Modus.

## Deploy

Netlify: Build `npm run build`, Publish `dist`. Env-Vars wie in `.env.example`.
