Privacy Policy

Last updated: November 16, 2026

This policy covers the Void Syndicate website (void-syndicate-954.netlify.app) and the Void Syndicate Bypass browser extension.

1. What we collect

  • API key (extension / website local storage): If you save a Void Syndicate API key, it is stored locally in your browser and sent only as the x-api-key header to our API when you request a bypass.
  • URLs you submit for bypass: Sent to our servers so we can resolve the destination link. We do not sell this data.
  • Basic technical logs: Our host (Netlify) may log standard request metadata (time, status code, IP) for reliability and abuse prevention.

2. What we do not collect

  • No account password for the extension
  • No browsing history beyond the URL you explicitly bypass
  • No sale of personal data to advertisers

3. How the extension uses permissions

  • storage — save your API key and last result locally
  • contextMenus — “Bypass with Void Syndicate” on right-click
  • activeTab / host access — read the current supported page URL to bypass it
  • clipboardWrite — copy the bypassed destination when you ask

4. Third parties

Bypass requests are processed by our API on Netlify. Upstream link-resolution providers may receive the target URL as part of fulfilling the bypass. Payment / key purchases are handled manually via Discord — we do not process card data on the website.
